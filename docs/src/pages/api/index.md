# API Reference

Detailed technical documentation for all exported classes, functions, and types across the DriftJS monorepo.

---

## Package Modules

* [**`driftjs-compiler`**](/api/compiler/): Ahead-of-Time compiler, lexer, parser, transformer, and bytecode generator.
* [**`driftjs-dom`**](/api/dom/): Browser client Virtual Machine (`DriftClientVM`), DOM mounter, hydrator, and reconciler.
* [**`driftjs-ssr`**](/api/ssr/): Headless server Virtual Machine (`DriftServerVM`), HTML serializer, and streaming renderer.
* [**`driftjs-shared`**](/api/shared/): Scope helpers, expression evaluator, context injection, and runtime constants.
